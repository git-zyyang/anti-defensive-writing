# Validation status · 验证状态

The initial public package is checked for portable relative links, Skill frontmatter, required references, matching license copies, readable image assets, and accidental inclusion of local/private material. The installation copy procedure is exercised in an isolated temporary directory.

首发包检查相对链接、Skill元数据、引用文件、许可副本、图片及本机与私人信息泄露风险；安装复制流程在隔离临时目录中执行。

These checks establish packaging integrity. They do not measure writing quality or prove that every host reliably selects the skill. The README's examples are constructed teaching material, not scored before/after model trials.

上述检查证明发布包的完整性，不作为写作效果或所有客户端自动触发能力的证据。README示例为教学材料，不是模型对照实验。

## A useful behavioral evaluation · 如何评价实际表现

Use a real task with permission to access its material. Record the input, genre, required facts, editing scope, host, model, and output. Compare the original and revised passages for explanation, evidence, inferential strength, reader comprehension, and voice. Include a case where a qualification must remain and a case where an apparently fluent edit loses something valuable.

采用有权使用的真实任务，记录输入、文体、事实、修改范围、运行环境、模型与输出。比较改前改后的解释、证据、推断力度、读者理解和声音；同时检查“必要限定应保留”和“通顺修改却损失价值”的情况。

Retain failures and adverse findings. Once a case has informed the instructions, treat it as a regression case rather than an independent holdout. Author acceptance must be recorded separately from an assistant's self-review.

保留失败和不利发现。用于改规则的案例此后属于回归案例，不能再称为独立留出。作者认可与助手自检分别记录。
